## QuickC for Windows 1.0 Test Files

*QuickC* is the name of a DOS based compiler first released in 1987. *QuickC for Windows 1.0* is the name of a compiler *designed for Windows 3.11* released in 1991. 1.0 is the version of this software; it's not for *Windows 1.0*
