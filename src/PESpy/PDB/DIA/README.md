This folder contains classes that have been reverse engineered from msdia140 that are so complicated, it makes sense to use them inline rather than try and rework into my own code style. Principally, we model an approximate representation of the `CAllSymsByAddrTrav` class and the hierarchy of classes it calls into for the purpose of resolving an RVA to a symbol. Minor changes to parameter lists have been made to facilitate exfiltrating the resolved symbol out of each traverser.
